# Birthday game audio

Upload your MP3 files directly into this `music` folder with these exact lowercase names:

- `intro.mp3`
- `thinking.mp3`
- `correct.mp3`
- `wrong.mp3`
- `buzzer.mp3`
- `steal.mp3`
- `win.mp3`

In GitHub, open this folder, click **Add file → Upload files**, drag your MP3s in, and commit changes. Back on the game host screen, click **Use uploaded music/ folder** then select a cue and test **Play track**. Audio is not included in this folder yet.
